### TypeScriptとは？

JavaScriptに「型」を追加した言語。

```typescript
// JavaScript（型なし）
let count = 0;
count = "hello";  // エラーにならない（バグの原因に）

// TypeScript（型あり）
let count: number = 0;
count = "hello";  // エラー！ 数値に文字列は入れられない
```

**メリット:**
- バグを事前に発見できる
- エディタの補完が賢くなる
- 大規模開発に向いている

## フレームワーク・ライブラリ

### 1. React（リアクト）

**役割:** ユーザーインターフェース（UI）を作るライブラリ

## 各ファイルの詳細解説

### index.html（エントリーポイント）

ブラウザが最初に読み込むファイル。

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>今日えらっ</title>
    <!-- Material Icons（アイコンフォント） -->
    <link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
  </head>
  <body>
    <!-- Reactがここに描画する -->
    <div id="root"></div>
    <!-- メインのスクリプト -->
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

**ポイント:**
- `<div id="root">` がReactアプリの描画先
- `<script src="/src/main.tsx">` でアプリを起動

### src/main.tsx（Reactの起動）

Reactアプリを起動するファイル。

```tsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'
import App from './App.tsx'

// 'root'要素を取得して、Reactをマウント（取り付け）
createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

**コード解説:**

| コード | 意味 |
|--------|------|
| `import` | 他のファイルから機能を読み込む |
| `createRoot()` | Reactのルートを作成 |
| `document.getElementById('root')` | HTMLの#root要素を取得 |
| `!` | 「絶対にnullじゃない」とTypeScriptに伝える |
| `.render()` | 画面に描画 |
| `<StrictMode>` | 開発時のエラーチェックを厳しくする |
| `<App />` | Appコンポーネントを表示 |

### src/components/GanbattaButton.tsx（メイン機能）

「頑張った！」ボタンのコンポーネント。

```tsx
import { useState, useEffect, useRef } from "react";
import { collection, addDoc, serverTimestamp, query, where, getDocs } from "firebase/firestore";
import { db } from "../firebase/config";

// 褒め言葉のリスト
const PRAISE_MESSAGES = [
  { text: "最高！", icon: "star" },
  { text: "すごいじゃん！", icon: "celebration" },
  // ... 省略
];

export const GanbattaButton = () => {
  // === State（状態）の定義 ===
  const [count, setCount] = useState(0);           // カウント
  const [message, setMessage] = useState(null);     // 表示中のメッセージ
  const [isAnimating, setIsAnimating] = useState(false);  // アニメーション中か

  // === Ref（参照）の定義 ===
  const animationTimerRef = useRef(null);

  // === Effect（副作用）===
  useEffect(() => {
    // コンポーネント表示時に今日のカウントを取得
    const fetchCount = async () => {
      const today = new Date().toISOString().split("T")[0];
      const q = query(collection(db, "clicks"), where("date", "==", today));
      const snapshot = await getDocs(q);
      setCount(snapshot.size);
    };
    fetchCount();
  }, []);

  // === イベントハンドラ ===
  const handleClick = () => {
    // カウントを増やす
    setCount((prev) => prev + 1);

    // ランダムなメッセージを選択
    const randomMessage = PRAISE_MESSAGES[Math.floor(Math.random() * PRAISE_MESSAGES.length)];
    setMessage({ ...randomMessage, key: Date.now() });

    // Firestoreに記録
    addDoc(collection(db, "clicks"), {
      date: new Date().toISOString().split("T")[0],
      timestamp: serverTimestamp(),
    });
  };

  // === JSX（表示内容）===
  return (
    <div className="ganbatta-container">
      <div className="count-display">今日の頑張り: {count}回</div>
      <button onClick={handleClick}>頑張った！</button>
      {message && <div className="praise-message">{message.text}</div>}
    </div>
  );
};
```

## Reactの重要概念

### 1. State（状態）

コンポーネントが持つ「変化するデータ」。

```tsx
// useStateの使い方
const [count, setCount] = useState(0);
//     ↑変数   ↑更新関数        ↑初期値

// 更新方法
setCount(5);           // 直接値を設定
setCount(prev => prev + 1);  // 前の値を使って更新
```

**Stateが変わると、自動で画面が再描画される！**

### 2. Props（プロパティ）

親から子に渡すデータ。

```tsx
// 親コンポーネント
function Parent() {
  return <Child name="太郎" age={20} />;
}

// 子コンポーネント
function Child(props) {
  return <p>{props.name}は{props.age}歳です</p>;
}
// または
function Child({ name, age }) {
  return <p>{name}は{age}歳です</p>;
}
```

### 3. useEffect（副作用）

「画面描画以外の処理」を実行。

```tsx
useEffect(() => {
  // 実行したい処理
  console.log("コンポーネントが表示された！");

  // クリーンアップ（コンポーネント削除時に実行）
  return () => {
    console.log("コンポーネントが削除された！");
  };
}, [依存配列]);  // この値が変わった時に再実行
```

| 依存配列 | 動作 |
|----------|------|
| `[]` | 初回表示時のみ実行 |
| `[count]` | countが変わるたびに実行 |
| なし | 毎回の描画で実行（非推奨） |

### 4. useRef（参照）

再描画をトリガーしない値を保持。

```tsx
const timerRef = useRef(null);

// タイマーIDを保存（stateと違い、変更しても再描画されない）
timerRef.current = setTimeout(() => {}, 1000);

// タイマーをキャンセル
clearTimeout(timerRef.current);
```

## Firestoreの基本操作

### データの追加

```typescript
import { collection, addDoc, serverTimestamp } from "firebase/firestore";
import { db } from "../firebase/config";

// "clicks"コレクションにドキュメントを追加
await addDoc(collection(db, "clicks"), {
  date: "2024-01-08",
  timestamp: serverTimestamp(),  // サーバー時刻
});
```

### データの取得

```typescript
import { collection, getDocs, query, where } from "firebase/firestore";

// 条件を指定してデータを取得
const q = query(
  collection(db, "clicks"),
  where("date", "==", "2024-01-08")
);
const snapshot = await getDocs(q);

// 結果をループ
snapshot.forEach((doc) => {
  console.log(doc.id, doc.data());
});
```

### リアルタイム監視

```typescript
import { collection, onSnapshot } from "firebase/firestore";

// データが変更されるたびにコールバックが呼ばれる
const unsubscribe = onSnapshot(collection(db, "clicks"), (snapshot) => {
  snapshot.forEach((doc) => {
    console.log(doc.data());
  });
});

// 監視を停止
unsubscribe();
```
